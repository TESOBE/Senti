Setup

What Senti watches and what it needs, read from its setup file, its .env and its own databases. Senti calls nothing to make this page. After you change senti.toml or .env, restart Senti and refresh this page.

Where the setup comes from

Claude Code

Senti runs Claude Code for the analyst, the source review, the replies to your comments and Fix this. Without it, Senti still watches but finds nothing.

Services

Each service is a piece of software Senti watches, with the checkout of its code. Fix this works in Senti's own git worktree next to the checkout, made the first time it is needed, and stages each fix in the checkout for you to commit.
